# 宝塔面板部署指南（Ubuntu 24）

> 目标：用最少的手动操作，把「奖学金材料审核工作台」部署到你的服务器。
> 你有两个选择，**推荐方式 A（SSH 终端一条命令）**。

---

## 方式 A：SSH 终端一键部署（操作最少，推荐）

### 前提
1. 代码已经上传到 GitHub（`https://github.com/liuxiansenlc/fudaoyuan.git`）
2. 你能 SSH 登录服务器（root 或 sudo 用户）

### 步骤

**1. 登录服务器**

在宝塔面板左侧「终端」，或本地 SSH 工具执行：

```bash
ssh root@115.159.211.111
```

**2. 把代码拿到服务器上**

```bash
cd /opt
git clone https://github.com/liuxiansenlc/fudaoyuan.git fudao
cd fudao
```

**3. 修改部署脚本里的两个占位符**

```bash
# 用 vi/nano 编辑，改两处：域名 + MySQL 密码
nano deploy/install.sh
```

找到这两行改掉：

```bash
DOMAIN="your-domain.com"                      # ← 改成你的真实域名
DB_PASS="CHANGE_ME_STRONG_PASSWORD"           # ← 改成强密码（MySQL root 密码）
```

> 说明：脚本会用这个密码自动建库 `fudao` + 用户 `fudao`。如果你的 MySQL root 密码不同，改 `DB_PASS` 为 root 密码即可；或者手动先建好库再跑脚本。

**4. 执行部署**

```bash
sudo bash deploy/install.sh
```

脚本会自动完成：装依赖 → 建虚拟环境 → 建 MySQL 库表（含中文注释）→ 生成 .env → 创建 systemd 服务 → 配 Nginx → 启动服务。

**5. 完成**，访问 `http://你的域名`，登录 `admin / 123456`。

## 方式 B：纯宝塔网页操作（不用终端，但要手动点多步）

### 1. 上传代码
- 宝塔 → 文件 → 进入 `/www/wwwroot` → 新建目录 `fudao`
- 把项目文件上传进去（或用宝塔的「远程下载」填 GitHub 的 zip 地址）

### 2. 创建 Python 项目（宝塔自带「Python 项目管理器」）
- 宝塔 → Python 项目管理器 → 添加项目
  - 项目路径：`/www/wwwroot/fudao`
  - 运行命令：`gunicorn -w 3 -b 127.0.0.1:8000 wsgi:app`
  - 运行用户：root（或 www）

### 3. 装依赖
- 在宝塔终端里 `cd /www/wwwroot/fudao && pip install -r requirements.txt`

### 4. 建 MySQL 库表
- 宝塔 → 数据库 → 添加数据库（库名 `fudao`，记下账号密码）
- 宝塔 → 数据库 → 导入 → 选择 `deploy/schema.sql`（这份脚本带中文注释）

### 5. 配置 .env
- 在项目根目录创建 `.env`，内容参考 `deploy/.env.example`，填 MySQL 连接信息

### 6. 反代
- 宝塔 → 网站 → 添加站点（填域名）→ 设置 → 反向代理 → 目标 `http://127.0.0.1:8000`
- 在 Nginx 配置里加 `client_max_body_size 200m;`（否则上传大文件会 413）

### 7. 启动读图 worker
- 宝塔 → 守护进程管理器 → 添加：`cd /www/wwwroot/fudao && python worker.py`

## 部署后必做的三件事

| 事项 | 位置 | 说明 |
|---|---|---|
| 改默认密码 | 右上角「我的账号」 | admin/123456 是公开默认值 |
| 配置大模型 | 「模型设置」 | 填 base_url + api_key + 模型名 |
| 上传参考数据 | 「参考数据」 | A 类竞赛表、成绩排名表 |

## 常见问题

**Q：上传大文件报 413？**
A：Nginx 没配 `client_max_body_size 200m;`，加上后 `nginx -s reload`。

**Q：图片识别不动、进度条卡住？**
A：worker 进程没启动，或模型没配。看日志：`journalctl -u fudao-worker -f`。

**Q：改了代码怎么更新？**
A：
```bash
cd /opt/fudao && git pull
systemctl restart fudao fudao-worker
```

**Q：MySQL 连接不上？**
A：确认 `.env` 里的 `WB_MYSQL_*` 和宝塔数据库的账号密码一致；确认 MySQL 允许 `127.0.0.1` 连接。

**Q：HTTPS 怎么开？**
A：宝塔 → 网站 → 设置 → SSL → 申请 Let's Encrypt 证书（一键）。
