# 部署操作清单（照抄即可）

> 你的环境：Ubuntu 24 + 宝塔 + 域名 dy.supermans.top + MySQL(dy 账号)
> 部署路径：/www/wwwroot/fudao
> 你只需要：复制粘贴命令 → 遇到需要确认时回车。

---

## 第一步：把代码放到服务器

二选一，**推荐方式 1**（宝塔网页上传，不用终端）：

### 方式 1：宝塔网页上传（推荐，最简单）

1. 本地把整个 `奖学金审核工作台` 文件夹**打成 zip**
2. 宝塔 → 文件 → 进入 `/www/wwwroot` → 新建目录 `fudao`
3. 点「上传」→ 选 zip → 上传完成后右键「解压」
4. 确保解压后是 `/www/wwwroot/fudao/` 下面**直接能看到 `wsgi.py`、`web/`、`deploy/`**（不是多套一层文件夹）

### 方式 2：SSH 终端 git clone

```bash
cd /www/wwwroot
git clone https://github.com/liuxiansenlc/fudaoyuan.git fudao
```

> 前提：代码已经 push 到 GitHub。如果之前没 push 成功，就用方式 1。

---

## 第二步：跑部署脚本

宝塔 → 终端（或 SSH 登录），执行：

```bash
cd /www/wwwroot/fudao
sudo bash deploy/install.sh
```

脚本会先**提示你输入 MySQL 密码**（dy 账号的密码），输入后回车继续。

> 如果你想一条命令带密码跑（不交互），用：
> ```bash
> cd /www/wwwroot/fudao
> DB_PASS=你的dy密码 sudo -E bash deploy/install.sh
> ```

脚本会自动：装依赖 → 建虚拟环境 → 建 MySQL 表（带中文注释）→ 生成配置 → 建 systemd 服务 → 启动。

**可能遇到的情况：**

- 如果提示 `dy 账号无建库权限`：去宝塔 → 数据库，手动建一个库名叫 `dy`，然后重新跑一次
- 如果卡在 pip 安装：耐心等，这是正常的（要装 python-docx、pillow 等）

---

## 第三步：在宝塔里加反向代理（让域名能访问）

因为脚本会自动跳过 Nginx（避免和宝塔冲突），你需要手动加一步反向代理：

1. 宝塔 → 网站 → 找到 `dy.supermans.top` 站点（没有就「添加站点」）
2. 点「设置」→「反向代理」→ 添加
   - 目标 URL：`http://127.0.0.1:8000`
   - 发送域名：`$host`（默认即可）
3. 点「配置文件」→ 确认有这行（没有就加上）：
   ```nginx
   client_max_body_size 200m;
   ```
   加完点「保存」

## 第四步：验证是否成功

浏览器打开：

```
http://dy.supermans.top
```

能看到登录页 = 部署成功。账号 **admin**，密码 **123456**。

如果打不开，看日志：

```bash

```

## 常见报错排查

### 遮挡敏感信息报 `ImportError: libGL.so.1: cannot open shared object file`

服务器（无图形界面的 Ubuntu）缺少 OpenCV 需要的系统库。执行一次即可：

```bash
apt-get update && apt-get install -y libgl1 libglib2.0-0
# 然后重启服务
```

或者改用无界面版 OpenCV：

```bash
cd /www/wwwroot/fudao
source venv/bin/activate      # 换成你的虚拟环境路径
pip install opencv-python-headless
```

> 说明：遮挡功能依赖 RapidOCR → OpenCV。系统库装好后，「模型设置 → 送模型前遮挡敏感信息」
> 卡片上会显示可用；若仍不可用，卡片上会有红字提示当前缺什么。

### 任务一直卡在「排队等待中」、进度 0%

说明**没有 worker 进程在跑**。批次页底部会显示「未检测到 worker」。两种解决方式：
- 简单：给项目加环境变量 `WB_INLINE_WORKER=1`，重启服务（Web 进程内嵌 worker）；
- 独立：`cd /www/wwwroot/fudao && source venv/bin/activate && python worker.py`，
  并用宝塔「进程守护/ Supervisor」托住它。
