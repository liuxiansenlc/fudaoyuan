# 宝塔面板部署（Linux）

面向：一台云服务器 + 宝塔面板 + 一个域名，多名辅导员同时使用。

---

## 0. 前置检查

| 项 | 要求 |
| --- | --- |
| 系统 | Linux（CentOS / Ubuntu 均可） |
| Python | 3.10+（3.13 已验证） |
| 数据库 | MySQL 5.7+ / 8.0（宝塔软件商店一键装） |
| 反向代理 | Nginx（宝塔自带） |
| 磁盘 | 预留 ≥ 5 GB（学生材料图片占空间最大） |

---

## 1. 上传代码

把整个 `奖学金审核工作台/` 目录上传到服务器，例如 `/www/wwwroot/scholarship/`。

> **不要**上传本地的 `data/` 和 `cache/`（里面是本机路径与调试数据）。
> 如果要把本地已审的数据一起带过去，见第 7 节迁移。

目录结构确认：

```
/www/wwwroot/scholarship/
├─ engine/          判定引擎
├─ web/             Flask 应用
├─ tools/           部署工具
├─ tests/           测试
├─ data/            运行时生成（上传/结果/导出）
├─ cache/           读图缓存
├─ wsgi.py  worker.py  requirements.txt
```

## 2. 建数据库

宝塔 → 数据库 → 添加数据库：

- 数据库名：`scholarship_audit`
- 用户名：`scholarship`
- 密码：**自己设一个强密码**
- 权限：本地服务器

> MySQL 8 默认认证插件是 `caching_sha2_password`，pymysql 支持；
> 若遇到 `Authentication plugin 'xxx' not supported`，在 phpMyAdmin 里执行：
> ```sql
> ALTER USER 'scholarship'@'%' IDENTIFIED WITH mysql_native_password BY '你的密码';
> FLUSH PRIVILEGES;
> ```

## 3. 装 Python 环境

宝塔 → 软件商店 → Python 项目管理器 → 安装 Python 3.11+，
然后在项目目录里建虚拟环境并安装依赖：

```bash
cd /www/wwwroot/scholarship
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 用国内源，`onnxruntime` / `opencv` 这类包从官方源会很慢。

## 4. 配环境变量

```bash
cd /www/wwwroot/scholarship
cp .env.example .env
vi .env
```

至少改这几项：

```ini
WB_DB=mysql
WB_MYSQL_HOST=127.0.0.1
WB_MYSQL_PORT=3306
WB_MYSQL_USER=scholarship
WB_MYSQL_PASSWORD=第2步设的密码
WB_MYSQL_DB=scholarship_audit
WB_INLINE_WORKER=0
WB_ADMIN_PWD=换一个只有你们知道的初始密码
```

## 5. 初始化数据库

```bash
source venv/bin/activate
python tools/init_db.py          # 建库建表 + 建管理员
python tools/init_db.py --check  # 自检：连通性 / 表数 / 用户数
```

看到 `自检：OK` 就说明数据库通了。

## 6. 起两个进程

### 6.1 Web 进程

宝塔 → Python 项目管理器 → 添加项目：

| 项 | 值 |
| --- | --- |
| 项目名称 | scholarship-web |
| 路径 | `/www/wwwroot/scholarship` |
| 启动方式 | gunicorn |
| 启动文件 | `wsgi:app` |
| 端口 | `8000` |
| 用户 | www |

等价的手工命令：

```bash
cd /www/wwwroot/scholarship
source venv/bin/activate
gunicorn -w 3 -b 127.0.0.1:8000 --timeout 300 wsgi:app
```

> `-w 3` = 3 个 worker。读图不在 Web 进程里跑，所以不需要很多 worker。
> `--timeout 300` 给导出大文件留余量。

### 6.2 读图 worker（**必须独立进程**）

宝塔 → 计划任务/守护进程 → 添加「守护进程」（或用 supervisor）：

```bash
cd /www/wwwroot/scholarship && source venv/bin/activate && WB_INLINE_WORKER=0 python worker.py
```

> ★ 生产环境**必须**把 Web 进程的 `WB_INLINE_WORKER` 设为 0。
> 否则读图跑在 Web 进程里，gunicorn 一重启（改配置、被守护重启）就把任务打断了。
> 独立 worker 可以随便重启 Web，任务继续跑；崩了还有 `requeue_stale` 把僵尸任务放回队列。

## 7. 配 Nginx 反代

宝塔 → 网站 → 添加站点（用你的域名）→ 设置 → 反向代理：

目标 URL：`http://127.0.0.1:8000`

然后到「配置文件」里补三行（**上传体积是必须改的**）：

```nginx
server {
    listen 80;
    server_name 你的域名;

    # 学生材料可能几十 MB，默认 1m 会直接 413
    client_max_body_size 200m;

    # 静态文件让 nginx 直接发，别过 Python
    location /static/ {
        alias /www/wwwroot/scholarship/web/static/;
        expires 7d;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

改完 `nginx -t` 通过后重载。

### HTTPS

宝塔 → 网站 → SSL → Let's Encrypt 一键签发。
签发成功后在 `.env` 里加一行并重启 Web 进程：

```ini
# 走 HTTPS 后把会话 Cookie 设为 Secure（模板里默认 False，见 web/config.py）
```

> 代码里 `SESSION_COOKIE_SECURE = False`。上了 HTTPS 后建议改成 `True`，
> 这样 Cookie 只走加密连接。改完记得重启 Web 进程。

## 8. 首次登录后立刻做的事

1. 浏览器打开 `https://你的域名`，用 `admin` / `.env` 里的初始密码登录。
2. 侧栏 → **我的账号** → 改掉密码（还在用默认值时页面顶部会一直红条提醒）。
3. **模型设置** → 填 base_url / api_key / 模型名 → 点「测试」确认连通。
   > 模型必须支持**读图**（多模态），否则读图会全失败。
4. **模型设置** → 按需打开「送模型前遮挡敏感信息」。
   > 成绩单、等级证书常带身份证号。只选承诺"不用于训练"的服务商；
   > 能本地部署就本地部署（Ollama + 视觉模型，base_url 填 `http://127.0.0.1:11434/v1`）。
5. **奖学金项目** → 建第一个奖学金（可套用预设方案）。
6. **参考数据** → 上传全校通用的 A 类竞赛表与成绩排名表。
7. **用户管理** → 给其他辅导员建号。

## 9. 日常运维

### 备份

需要备份的是**两块**：

```bash
# 1) 数据库
mysqldump -u scholarship -p scholarship_audit > backup_$(date +%F).sql

# 2) 文件（上传材料、结果、导出、读图缓存、密钥）
tar czf data_$(date +%F).tar.gz \
    data/uploads data/results data/images data/exports data/instance \
    cache/
```

> `data/instance/` 里是会话密钥和 api_key 加密主密钥。**丢了 api_key 就得重填**，
> 备份时别落下。

宝塔 → 计划任务 → 加两条每日备份。

### 升级代码

```bash
cd /www/wwwroot/scholarship
git pull                # 或覆盖上传新代码
source venv/bin/activate
pip install -r requirements.txt
python tools/init_db.py            # 幂等：自动补列 / 改列名 / 建索引
# 重启 Web 进程；worker 会自动用新代码（重启守护进程更稳）
```

### 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 上传大文件报 413 | nginx `client_max_body_size` 没改 |
| 页面样式全丢 | nginx 的 `/static/` 路径写错 |
| 读了半天没进度 | worker 没起，或 `WB_INLINE_WORKER` 配成了 1 但 worker 也在抢任务 |
| 报 `Authentication plugin ... not supported` | MySQL 认证插件问题，见第 2 节 |
| 报 `database is locked` | 你用的是 SQLite 却多进程写。生产请用 MySQL |
| 改了模板页面没变化 | 已默认开 `TEMPLATES_AUTO_RELOAD`；若设了 `WB_TEMPLATE_RELOAD=0`，需重启 |
| 任务卡在 running | `requeue_stale` 会在 20 分钟后自动放回队列；也可重启 worker |
| 导出报内存不足 | 单个批次太大时分开导出；或把 gunicorn `--timeout` 调大 |

### 时区

数据库里存的是 **UTC**，界面上统一按**北京时间**显示，不用额外配置。
服务器时区不对也不影响显示。

## 10. 容量与成本

| 项 | 估算 |
| --- | --- |
| 单个学生材料 | docx 几百 KB ~ 2 MB；图片按 sha256 去重后另存一份 |
| 13 个学生 | `data/images` 约 40 MB |
| 读图成本 | 按 `sha256` 缓存，**同一张证书终身只读一次**；跨批次、跨学年都复用 |
| 每日闸门 | `VISION_DAILY_LIMIT`（默认 2000 张/天）在 `web/config.py` 里调 |

> 成本上最要紧的是"缓存命中"。学生重复交同一张证书、往年用过的证书，
> 只要 sha256 一样就不会重复调模型。所以第二年重跑，绝大部分图是零成本。

## 11. 安全清单

- [ ] 改掉 admin 默认密码
- [ ] 关闭自助注册（`ALLOW_SELF_REGISTER = False`，默认已关）
- [ ] 上 HTTPS，并把 `SESSION_COOKIE_SECURE` 改为 `True`
- [ ] MySQL 只监听 127.0.0.1，不对公网开放
- [ ] `data/instance/` 目录权限 600
- [ ] nginx 只暴露 80/443，8000 端口不对外
- [ ] 按需开启「送模型前遮挡敏感信息」
- [ ] 只给需要的人建账号；离岗人员及时停用
