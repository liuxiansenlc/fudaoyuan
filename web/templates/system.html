部署要点（宝塔 / Linux）

1) 装依赖
     cd 奖学金审核工作台 && pip install -r requirements.txt

2) Web 进程（gunicorn，宝塔「Python 项目管理器」里加）
     gunicorn -w 3 -b 127.0.0.1:8000 wsgi:app

3) 读图 worker（独立进程，宝塔「守护进程」里加）
     WB_INLINE_WORKER=0 python worker.py

   ★ 生产环境务必把 Web 进程的 WB_INLINE_WORKER 设为 0，
     否则 gunicorn 重启会打断正在跑的读图任务。

4) nginx 反代
     client_max_body_size 200m;
     location / { proxy_pass http://127.0.0.1:8000; proxy_set_header Host $host; }

5) 上传的图片与结果都在 data/ 下，备份这个目录即可
